# 🏫 Descubriendo Jardín Maternal 

🌐 **Sitio Web **: [jardinmaternaldescubriendo.vercel.app](https://jardinmaternaldescubriendo.vercel.app/)

## ⭐ Proyecto Top 10 - Coderhouse
Este proyecto web fue realizado como trabajo final del curso de **Desarrollo Web en Coderhouse**, habiendo obtenido un lugar dentro del **Top 10 de la camada** por el diseño, la calidad del código y la entrega del sitio.

---

## 📌 Descripción del Proyecto
Sitio web institucional para el **Jardín Maternal Descubriendo** (San Miguel, Buenos Aires). La plataforma tiene como objetivo brindar a las familias una experiencia clara, interactiva y atractiva para conocer la propuesta educativa, las salas, actividades, preguntas frecuentes y canales directos de contacto.

---

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica del sitio.
- **CSS3**: Estilos personalizados, CSS Grid, Flexbox y animaciones.
- **JavaScript (ES6+)**: Lógica e interactividad (slider, menú responsive y validación de formulario).
- **Bootstrap 5**: Maquetación utilitaria y componentes adaptativos.
- **Font Awesome & SVG**: Iconografía vectorial moderna.

---

## ✨ Características Principales

- 📱 **Diseño 100% Responsive**: Adaptado para celulares, tablets y computadoras.
- 🖼️ **Slider de Imágenes Interactivo**: Galería dinámica en la sección principal.
- 📋 **Formulario de Contacto Interactivo**: Validación en tiempo real con JavaScript.
- ❓ **Sección de Preguntas Frecuentes**: Respuestas rápidas a dudas habituales.
- 📍 **Integración con Google Maps y Redes Sociales**: WhatsApp, Instagram, Facebook y localización.
